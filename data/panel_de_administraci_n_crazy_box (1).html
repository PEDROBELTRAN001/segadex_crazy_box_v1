Si deseas que el panel lea y guarde en data/prizes_config.json de forma 100% instantánea al abrir la página sin tocar ningún botón de conectar, guarda este pequeño script como admin_server.py junto a tu panel.html y ejecútalo: 

import http.server, json, os

PORT = 8090
JSON_PATH = os.path.join("data", "prizes_config.json")

class Handler(http.server.SimpleHTTPRequestHandler):
    def do_GET(self):
        if self.path.startswith("/api/prizes"):
            self.send_response(200)
            self.send_header("Content-Type", "application/json; charset=utf-8")
            self.end_headers()
            with open(JSON_PATH, "rb") as f:
                self.wfile.write(f.read())
            return
        return super().do_GET()

    def do_POST(self):
        if self.path.startswith("/api/prizes"):
            length = int(self.headers.get("Content-Length", 0))
            body = self.rfile.read(length).decode("utf-8")
            os.makedirs("data", exist_ok=True)
            with open(JSON_PATH, "w", encoding="utf-8") as f:
                f.write(body)
            self.send_response(200)
            self.send_header("Content-Type", "application/json")
            self.end_headers()
            self.wfile.write(b'{"ok":true}')
            return

print(f"Panel Crazy Box activo en: http://localhost:{PORT}/panel.html")
http.server.HTTPServer(("127.0.0.1", PORT), Handler).serve_forever()
Ejecuta en terminal: python admin_server.py y abre http://localhost:8090/panel.html. El panel detectará automáticamente la API /api/prizes.
